# Alanya İklim Laboratuvarı — ayrı GitHub Pages sitesi

1. GitHub Desktop: File > New repository. Ad: alanya-climate-lab.
2. Yeni deponun klasörünü açın. Bu paketteki alanya-climate-lab klasörünün içeriğini oraya kopyalayın. index.html, assets ve data aynı seviyede olmalı.
3. GitHub Desktop: Commit to main, ardından Publish repository. Herkese açık depo için Keep this code private işaretini kaldırın.
4. GitHub: depo > Settings > Pages. Source: Deploy from a branch; Branch: main; Folder: /(root); Save.
5. Yayımlama tamamlandığında: https://murataksel.github.io/alanya-climate-lab/

Yerel deneme için index.html dosyasını çift tıklayın. Kurulum gerektirmez.
